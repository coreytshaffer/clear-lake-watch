# Personal Knowledge-Base

This folder is an Obsidian-friendly Markdown vault. It is designed to stay
simple: no plugins, no complex taxonomy, and no pressure to make every note
perfect.

Open `START_HERE.md` first.

## Folder Map

- `00-inbox`: fast capture.
- `10-projects`: active project notes.
- `20-areas`: ongoing learning areas.
- `30-resources`: sources, methods, and reusable references.
- `40-next-actions`: small next steps.
- `90-templates`: optional note templates.
