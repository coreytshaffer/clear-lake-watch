# Clear Lake Watch

## Purpose

Build a public-source dashboard for Clear Lake environmental situational
awareness while keeping methodology, data limitations, and public-health
boundaries explicit.

## Why This Exists

Clear Lake has environmental monitoring needs that involve water quality,
cyanobacterial bloom context, public advisories, weather drivers, watershed
conditions, and long-term community trust. This project should help people
understand available public information without implying official health
guidance.

## Current Shape

- Static public dashboard in this repository.
- Public data sources only for the published view.
- Methodology and project-roadmap details separated from the main dashboard.
- Weather context treated as environmental driver data, not a lake-health claim.

## Open Questions

- Which public sources are reliable enough for routine refresh?
- What belongs on the public dashboard versus the project page?

## Decisions

- Keep public-health language conservative.
- Mark missing or stale data clearly.
- Prefer a working, trustworthy dashboard over broad feature expansion.
