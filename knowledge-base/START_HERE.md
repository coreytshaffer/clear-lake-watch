# Start Here

This knowledge-base is intentionally small. Use it as a calm place to catch,
shape, and reuse your thinking without needing to understand the full Obsidian
interface.

## Daily Use

1. Put rough thoughts in [[00-inbox/inbox]].
2. Move useful project details into [[10-projects/Clear Lake Watch]].
3. Save reusable facts, methods, and sources in [[30-resources/source-notes]].
4. Review [[40-next-actions/next-actions]] when you want one clear next step.

## Ground Rules

- Capture first, organize later.
- One note can be messy.
- Prefer short notes over perfect notes.
- Link notes only when the link helps you find something again.
- Do not mix public lake-health claims with private project planning.
