# Public Backlog

Status: public roadmap index

This backlog tracks the next conservative improvements for Clear Lake Watch after the first public mirror release. The project remains a late prototype / early MVP and is not official public-health guidance, an official advisory, a validated forecast, or a deployed sensor network.

## Current Focus

The next work should strengthen trust before expanding authority:

1. clarify snapshot freshness,
2. review unresolved map/site assignments,
3. harden validation,
4. design repeatable public refresh,
5. keep future telemetry and field records behind reviewed publication boundaries.
