# Internship Role Fit Map

Status: draft for career-services and internship search use

Date prepared: 2026-05-06

This map translates Clear Lake Watch into internship role families. It is meant to help career services connect the project to real search terms, resume language, and employer needs.

## Strongest Fit

### Environmental Data / Monitoring Intern

Why Clear Lake Watch fits:

- integrates public water-quality and hydrology data
- tracks source freshness and generated data products
- separates observed, reported, derived, and needs-review signals
- uses validation checks before treating outputs as shareable

Evidence to show:

- dashboard source-status panel
- `data/manifest.json`
- `scripts/validate-dashboard.ps1`
- methodology page

Search terms:

- environmental data intern
- environmental monitoring intern
- water quality data intern
- data stewardship intern
- environmental analyst intern

### GIS / Spatial Analysis Intern

Why Clear Lake Watch fits:

- organizes lake context around arms, shoreline geometry, coordinates, and map markers
- documents site-registry QA and review status
- keeps uncertain spatial assignments visible
- avoids promoting unreviewed site locations as authoritative

Evidence to show:

- map trust filter
- site-registry QA strip
- `data/sites.json`
- `docs/site-registry-location-verification.md`

Search terms:

- GIS intern
- spatial analyst intern
- environmental GIS intern
- geospatial data intern
- watershed GIS intern

### Water Resources / Watershed Intern

Why Clear Lake Watch fits:

- focuses on Clear Lake as a watershed system
- connects lake-level, tributary, bloom-report, and public source context
- supports research planning rather than official advisories
- frames water-quality communication conservatively

Evidence to show:

- live dashboard
- methodology page
- case study problem statement
- hydrology and FHABS source cards

Search terms:

- water resources intern
- watershed intern
- water quality intern
- watershed planning intern
- lake management intern

## Resume Bullet Variants

Environmental data version:

Built Clear Lake Watch, a late-prototype environmental data dashboard for Clear Lake, CA, integrating public hydrology and harmful-algal-bloom report data with source-status metadata, validation checks, and conservative public methodology guardrails.

GIS version:

Developed Clear Lake Watch, a watershed dashboard prototype using shoreline geometry, lake-arm grouping, site-registry QA, and map trust cues to communicate spatial uncertainty around Clear Lake monitoring data.

Water resources version:

Created a Clear Lake watershed intelligence prototype that combines public water-quality reports, USGS hydrology context, lake-arm summaries, and methodology notes to support research planning without replacing official guidance.

Data systems version:

Built a static, local-first environmental dashboard workflow using JSON data products, Python/PowerShell validation scripts, SQLite-backed private review stores, and public-safe exports for Clear Lake monitoring context.

## Career Services Ask

Ask career services to help map Clear Lake Watch to:

## Boundary Reminder

Do not frame Clear Lake Watch as a complete monitoring system, official guidance, validated forecast, deployed sensor network, or public submission platform.

Use:

- late prototype / early MVP
- watershed intelligence prototype
- environmental data dashboard
- portfolio systems-integration artifact
- research-planning and situational-awareness surface
