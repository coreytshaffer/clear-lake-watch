## Thirty-Second Pitch

Clear Lake Watch is my flagship environmental systems portfolio project. It is a late-prototype / early-MVP watershed intelligence dashboard for Clear Lake, California that combines public water-quality and hydrology data, GIS context, source-status metadata, site-registry review cues, and conservative public methodology language. It is designed as a situational-awareness and research-planning prototype, not official public-health guidance.

## Main Ask

Can you help me identify internship roles where Clear Lake Watch is strong evidence of fit, especially roles involving water quality, GIS, watershed planning, environmental monitoring, climate resilience, environmental data systems, or public-sector environmental communication?

## Three Questions To Prioritize

1. Which internship titles should I search for first?
2. Which resume bullet or project description is strongest for those roles?
3. Does any project wording feel overstated for an internship audience?

## If There Is Extra Time

- Ask whether to lead with the dashboard, case study, or methodology page.
- Ask whether "watershed intelligence dashboard prototype" makes sense to employers.
- Ask which screenshots would be most useful for applications.
- Ask whether the project reads more strongly as environmental science, GIS, data systems, or public communication.

## Safe Boundary Language

Use:

- late prototype / early MVP
- watershed intelligence dashboard prototype
- environmental data dashboard
- portfolio systems-integration artifact
- situational-awareness and research-planning surface

Avoid:

- official advisory
- official monitoring platform
- deployed sensor network
- validated forecast
- public-health guidance
- public field-submission system
